Menghitung penerima…
Satu nomor wali hanya menerima satu pesan, walau punya lebih dari satu anak. Pengiriman memakai jeda singkat agar nomor WhatsApp tidak diblokir.
Kirim Ringkasan Laporan Bulanan
Wali menerima ringkasan jumlah catatan anaknya pada bulan itu (kebaikan, prestasi, pelanggaran, tidak masuk, dan capaian program sekolah). Isi pesan dapat diubah di tab Pengaturan.
Koneksi Fonnte
Pakai token device (menu Device di fonnte.com), bukan token akun. Device harus berstatus Connected.
Aturan & Isi Pesan
Otomatis = pesan terkirim ke wali saat catatan disimpan (maksimal 10 siswa per kejadian). Uraian kejadian ikut terkirim, jadi jangan menulis nama siswa lain di uraian.
Variabel: {wali} {siswa} {kelas} {kategori} {tanggal} {jam} {uraian} {tindaklanjut} {pencatat} {madrasah}

Cadangan Data (Backup)

Backup berisi seluruh data: siswa, catatan, pengguna (termasuk sandi terenkripsi), pengaturan, dan log. Simpan berkasnya di tempat aman (Google Drive pribadi / flashdisk) dan jangan dibagikan. Token WhatsApp tidak ikut tersimpan.

Pulihkan dari Backup
Memulihkan akan mengganti semua data saat ini dengan isi berkas backup. Sistem otomatis mengunduh backup data saat ini lebih dulu sebagai pengaman.
